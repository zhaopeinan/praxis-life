如何区分新版和旧版高级权限

如果你看到的界面是下图，说明你在使用的是旧版高级权限。你可以参考下文“旧版高级权限”中的内容来了解行列权限，也可以点击 去体验 升级到新版高级权限。关于新版高级权限的更多信息，请参考多维表格高级权限全新版本。

如果你看到的界面是下图，说明你已经在使用新版高级权限。请参考下文“新版高级权限”中的内容来了解行列权限。

新版高级权限

当数据表权限为 可管理 时，记录权限和字段权限都默认取最大权限，且不可修改。此时，用户对全部行和列都拥有新增、编辑和删除的权限。

当数据表权限为 可编辑 时，你可以进一步设置角色的行列权限，包括是否可新增记录、可删除记录，角色可编辑和阅读的记录范围，还可以设置每个字段的新增、编辑和阅读权限等。

当数据表权限为 仅可阅读 时，记录权限和字段权限最大为“可阅读”，不允许新增、编辑和删除。你可以进一步设定可阅读的记录范围和字段范围。

当数据表权限为 无权限 时，无法设置行列权限。

所有者 和 管理员，默认对多维表格拥有最高权限，且不可修改。因此，所有者 和 管理员 对所有数据表都拥有可管理权限，对全部行和列都拥有新增、编辑和删除的权限。

编辑者 对数据表的权限可设置为 可管理、可编辑、仅可阅读 和 无权限。根据数据表的权限，角色可对行列权限进行不同程度的设置。

阅读者 对数据表的权限只有 仅可阅读 和 无权限 两类。若数据表权限为 仅可阅读，则可以进一步设定可阅读的记录范围和字段范围；若数据表权限为 无权限，则无法设置行列权限。

字段权限（列）

所有字段内容可编辑：该角色可以看到数据表中的所有字段，且能够编辑所有字段的内容，但不能新增或删除字段，也无法更改字段类型和字段名称。

若数据表内有单选或多选字段，该角色无法增删改选项。

若数据表内有附件字段，该角色默认拥有附件的下载权限，但还会受到下载多维表格的权限控制。无法下载多维表格的用户，无法导出附件。

自定义权限：勾选 自定义权限 后，你可以针对每一个字段分别设置是否 可阅读、可新增 和 可编辑，还可以设置单选、多选字段的增删改选项的权限，以及附件字段的导出（即下载）权限。

字段内容权限：

在记录权限中勾选了 可新增记录 之后，才可以在字段权限中勾选 可新增。当用户新增一条记录时，只能够在勾选了 可新增 的字段中输入内容，未勾选的字段无法编辑。

如果勾选了 可编辑，将自动获得 可阅读 和 可新增 的权限。如果勾选了 可新增，将自动获得 可阅读 的权限。

索引列默认勾选 可阅读，不能被设置为不可见。

系统字段（即创建人、修改人、创建时间、最后更新时间字段）默认勾选 可阅读，不能被设置为不可见。同时，由于系统字段的内容是自动填入的、不可编辑，因此不支持勾选 可新增 和 可编辑。

公式字段、查找引用字段、自动编号字段，以及人员字段“获取更多信息”生成的拓展字段，均为自动填入或自动计算的字段，因此不支持勾选 可新增 和 可编辑。

如果某个字段在“满足特定条件的记录”中被设置为了筛选条件，那么该字段必须为 可阅读 且 可新增，不可取消勾选。

选项权限：若数据表中有单选或多选字段，勾选 自定义权限 后，可以设置是否 可增删改选项。此处只能勾选当前角色有编辑权限的单选或多选字段。

注：已在该角色无编辑权限的记录中被使用的选项不支持被删除。

操作权限：若数据表内有附件字段，勾选 自定义权限 后，可以设置是否 可导出附件。当前角色需要对附件字段至少拥有可阅读权限，才能进行导出。

在高级权限的 其他功能权限 中，若未勾选 创建副本、下载、打印多维表格，说明此角色不允许下载多维表格，此时默认不允许导出附件，复选框无法勾选。

在通用的权限设置面板中（路径：多维表格右上角的 分享 > 权限设置），有 谁可以创建副本、打印和下载 的设置，用户需要同时满足通用权限和高级权限的权限要求，才能够进行操作。

可编辑：指定字段内容

可对记录进行的操作：可设置是否 可新增 和 可删除 记录。此时，该角色可阅读、可编辑所有记录。具体的编辑权限取决于字段是否可编辑。

可针对每一个字段分别设置是否 可阅读、可新增 和 可编辑。具体逻辑和限制条件同上，请参考“可编辑：与成员自己相关的记录”的字段权限中“自定义权限”的描述。

可编辑：自定义范围

可对记录进行的操作：可设置是否 可新增 和 可删除 记录。可编辑和删除的记录范围：可选择 所有记录 或 指定记录。选择 指定记录 后，可以设置筛选条件，该角色将只能编辑和删除满足条件的记录。支持将单选字段、多选字段、人员字段、流程字段、创建人字段、及输出结果为前述字段类型的公式字段和查找引用字段设置为筛选条件。当你设置了多个筛选条件时，可在右上角选择满足所有条件或任一条件。

可编辑和删除的记录范围：可选择 所有记录 或 指定记录。选择 指定记录 后，可以设置筛选条件，该角色将只能编辑和删除满足条件的记录。

支持将单选字段、多选字段、人员字段、流程字段、创建人字段、及输出结果为前述字段类型的公式字段和查找引用字段设置为筛选条件。

当你设置了多个筛选条件时，可在右上角选择满足所有条件或任一条件。

可以选择 所有字段内容可编辑 或 自定义权限。具体逻辑和限制条件同上，请参考“可编辑：与成员自己相关的记录”的字段权限的描述。
