二、操作流程

文档内的仪表盘图表默认继承原仪表盘权限，访问者可见数据与其直接访问原仪表盘时一致。

若多维表格开启了高级权限且原仪表盘开启了“跟随访问者权限统计”功能，但希望在文档中查看图表时所有访问者看到的视图一致，可将该图表复制到新仪表盘，关闭“跟随访问者权限统计”功能后再将图表插入文档。

进入多维表格的仪表盘页面。

在需要插入到文档的图表右上角点击 ⋮ 图标 > 复制 > 复制到文档。

注：如果不显示 复制到文档 的选择，说明该图表不支持被复制到文档。

当页面弹出“复制成功”的提示后，打开需要插入仪表盘图表的飞书文档。

在合适的位置点击鼠标右键并选择 粘贴，或者使用 Ctrl + V（Windows）或 Command + V（Mac）快捷键将该图表粘贴至文档。

源仪表盘图表有变更时，文档中的图表会自动更新，与源图表保持实时同步。

一篇飞书文档中最多可以添加 100 张仪表盘图表。

（可选）仪表盘图表首次粘贴到文档后，源多维表格默认会自动为该文档的协作者授予阅读权限，你可以点击“调整授权”修改权限。

（可选）仪表盘图表插入文档后，你可以按需对图表进行如下操作。

将鼠标悬停在图表上，点击浮现的 图标，可选择缩进与对齐、评论、剪切、复制、删除等操作。

将鼠标悬停在图表上，在图表上方浮现的工具栏中可以按需手动更新图表、打开源仪表盘、将图表下载为图片等。

三、常见问题

问：为什么我在文档中无法查看某些仪表盘图表？

答：可能是因为你没有源仪表盘的阅读权限。如果缺少源仪表盘权限，系统会提示无权限并引导你申请权限。
