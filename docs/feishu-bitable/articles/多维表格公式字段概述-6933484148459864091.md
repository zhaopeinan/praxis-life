创建和编辑公式字段

在多维表格文件中，打开需要创建公式字段的数据表，点击表头右侧的 + 图标新建字段，输入字段标题，选择 公式 作为字段类型。

点击 编辑公式 图标，进入公式编辑器，输入公式，完成后点击 确认。

点击 确定。

要快速编辑已创建的公式字段，可双击该字段中的任意记录打开公式编辑器。如果只需要对当前数据表中的数字字段进行加、减、乘、除操作，可点击编辑器右下角的 进入极简模式，选择对应的字段和运算符即可。

在公式字段内输入的公式会作用于字段内的所有记录。

在多维表格中，仅公式字段支持填写公式，其他字段不支持。

引用字段中的数据

引用当前数据表中的字段：当前数据表中的字段会被展示在公式编辑器左侧的 字段引用 中，编写公式时可直接点击引用。

跨数据表引用字段：可引用的其他数据表会被展示在公式编辑器左侧的 整表引用 中，编写公式时可直接点击引用。然后在被引用的数据表中选择字段即可。

四、常见问题

问：多维表格中“不等于”如何表示？

答： != 在多维表格函数中表示为“不等于”。

问：多维表格函数里的空值如何表示？

答：可以在公式中直接输入 ="" ，或者使用 ISBLANK() 函数。

问：如何在多维表格函数中输入表情或符号？

答：Mac 系统：在编写公式时，文本输入过程中，点击鼠标右键，进入 表情符号与符号 ，选择任意表情即可。Windows 系统：在编写公式时，文本输入过程中，同时点击 win键 和 。（句号），进入 表情符号键盘，选择任意表情即可。

问：多维表格公式字段是否可转换为其他字段类型？

答：支持，公式字段可以调整为文本字段、数字字段、多选字段、单选字段等字段类型，但仅保留计算后的结果；调整后字段将不再具备公式计算的能力。

问：多维表格公式字段中进行求和运算时，返回值为空或错误怎么办？

答：可能是字段类型不支持求和运算，当前无法对文本类型的字段进行求和，建议先将字段调整为数字类型后尝试。

问：多维表格公式字段运算完成后如何调整内容格式？

答：公式运算完成后如需调整返回值格式，可双击该公式字段，在弹出页找到 字段格式 调整当前字段返回值的格式，在 数字格式 处调整返回值的数据格式。

问：如何将多维表格公式字段转为其他字段？

答：双击公式字段，在弹出的配置面板里，将 字段类型 调整为其他字段即可。注：公式字段调整为其他字段后将失去公式自动计算的能力，仅保留调整后字段的特征。因公式字段返回值拥有多种格式类型，调整为其他字段后可能会出现不适配现象。

问：在多维表格数据表中引用字段时，引用结果有特定顺序吗？

答：引用数据返回多个值时没有特定的排序规则。

问：在多维表格同一列但不同行的单元格中，可以使用不同公式吗？

答：不支持。多维表格同一列所有单元格中的公式相同。
