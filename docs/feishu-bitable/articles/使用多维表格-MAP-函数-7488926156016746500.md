## 详细功能说明

一、MAP 函数介绍

二、函数语法

函数公式：MAP(数据范围, 映射逻辑)

参数释义：

数据范围：需按照自定义映射逻辑批量处理的一组数据，可使用 [数据表] 或 [数据表].[字段] 的方式引用数据表中的字段。有关如何在公式中引用数据表字段的具体信息，请参考通过公式字段引用数据。

映射逻辑：用来批量处理数据的规则。

注：在映射逻辑中，需使用 CurrentValue 变量指代当前正被处理的元素。有关 CurrentValue 变量的具体信息，请参考统计函数与 CurrentValue。

举例：如需批量将一组英文小写字母转换为大写字母，可以使用公式：MAP(LIST("a", "b"), UPPER(CurrentValue)) 进行转换。示例公式中使用了 LIST 函数将文本 a 和 b 转换为一个数组，公式输出以英文逗号分隔的大写字母 A 和 B。

三、操作流程

打开一个多维表格数据表。

点击数据表字段名最右侧的 + 图标新增字段，选择 公式 作为字段类型。你也可以双击已创建公式字段的字段名，对该公式字段进行编辑。

点击公式内容下的 编辑公式 图标，输入含有 MAP 函数的公式，点击 确认。

四、应用案例

按类别生成书籍列表并批量添加书名号

场景：书籍清单表（下左图）中列出了书名和书籍类别，可通过使用 FILTER 函数和 MAP 函数，将该表格中的书籍按类别进行统计（下右图），并给每本书添加书名号。

公式：[书籍清单].FILTER(CurrentValue.[类别]=[类别]).[书名].MAP("《" & CurrentValue & "》")

说明：首先使用 FILTER 函数，以两张表的 类别 列值相等为筛选条件，从书籍清单中按类别筛选书籍，并生成按类别划分的列表。MAP 函数将遍历每个列表，为其中的每本书添加书名号。
