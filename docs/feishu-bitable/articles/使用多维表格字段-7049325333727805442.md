一、功能简介

字段类型

输入较长的文本内容，支持表情等各种特殊符号，在单元格内可以通过按下 Shift + Enter 或 CTRL + Enter （Windows）或 Command + Enter （Mac）换行。

用于给记录打标签，可以自定义颜色和选项内容，在单元格内只能选择一个选项。

用于给记录打标签，可以自定义颜色和选项内容，在单元格内可以选择多个选项。

可以填入内部成员或外部联系人，可以同时添加多个人员。

可填入内部或外部群组。

支持以多种格式显示日期与时间。

支持上传多种文件类型的附件。

支持通过小数、百分比等形式展示数字。

可勾选的小方块，可快速标记记录为“完成”状态。

输入网页地址，可以自定义网址的文本名称。

可以通过丰富的函数公式对字段进行计算。

查找引用

基于 FILTER 函数的字段，可以快捷查找统计数据。

可自定义流程节点名称、展示事件当前状态。

自动化流程的触发条件，点击按钮可触发自动化操作。

自动编号

为每一条记录生成唯一可识别且自动递增的编号。

电话号码

录入并管理联系人的电话号码，在移动端可便捷拨打电话或发送短信。

Email

录入人员的邮箱地址，可校验邮箱格式并便捷发送邮件。

地理位置

快速记录位置信息或获取实时地理位置。

通过移动端自动扫描并识别条形码、二维码中的信息。

通过进度条视觉化直观展示项目进程。

根据不同市场或数据使用对象，选择相应的货币。

用于评价、调研等场景，可自定义评分范围及图形。

用于审批确认、门店巡检、验收、培训签到、会议签到等场景中的签字留痕。

双向关联

对两个数据表中的数据进行双向关联。

单向关联

对两个数据表中的数据进行单向关联。

每一条记录的创建者，由系统自动生成。

每一条记录的最后修改人，由系统自动生成。

创建时间

每一条记录的创建时间，由系统自动生成。

最后更新时间

每一条记录最后一次被修改的时间，由系统自动生成。

二、操作流程

新建字段

通过方式 1、2、3 新建字段时，你可以选择多维表格智能生成的推荐字段。

管理字段

修改字段标题与类型：可通过以下方式实现。

直接双击字段名称。

鼠标右键点击字段名称，或是将鼠标悬停在字段名称上并点击右侧的 ，选择 修改字段/列。

修改字段描述：鼠标右键点击字段名称，或是将鼠标悬停在字段名称上并点击右侧的 ，选择 编辑字段/列描述。

复制或删除字段：鼠标右键点击字段名称，或是将鼠标悬停在字段名称上并点击右侧的 ，按需选择 复制字段/列，或是 删除字段/列。

另外，点击 字段配置，再点击字段名称右侧的 ··· 图标 > 删除 也可以删除字段。

隐藏或显示字段：

隐藏已有字段：鼠标右键点击字段名称，或是将鼠标悬停在字段名称上并点击右侧的 ，选择 隐藏字段/列。

或者，点击 字段配置，点击 图标即可调整字段的显示或隐藏状态。通过这种方式，你可以让被隐藏的字段重新显示在视图中。

冻结字段：以下 2 种方式均可冻结字段。

鼠标右键点击某字段名称，或是将鼠标悬停在字段名称上并点击右侧的 ，选择 冻结至此字段/列。此时，从索引列到这一选定字段，从左到右的所有字段都会被冻结。不支持对其中的某个字段单独取消冻结。

将鼠标悬停在冻结线上，左右拖拽即可调整冻结范围。

调整字段顺序：以下 2 种方式可调整字段顺序。

单击字段名称以选中，左右拖拽字段即可调整顺序。

点击 字段配置，拖拽最左侧的 ⋮⋮ 即可调整字段顺序。适用于字段较多、横向拖拽不便的情况。
