## 详细功能说明

一、简介

消息内容 1.0 版本：支持基础 Markdown 语法，如加粗、斜体、删除线、超链接等。

消息内容 2.0 版本：除了基础 Markdown 语法，还支持高级 Markdown 语法，如标题格式、引用、表格等，同时支持部分 HTML 语法，如标签、含图标的链接等。
