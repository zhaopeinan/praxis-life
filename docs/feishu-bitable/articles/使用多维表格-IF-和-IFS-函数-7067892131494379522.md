一、IF() 和 IFS() 函数介绍

逻辑表达式：判断比较值和期待值的逻辑条件

为 TRUE 时返回的结果：当满足逻辑表达式中设置的条件时，返回的结果

为 FALSE 时返回的结果：当不满足逻辑表达式中设置的条件时，返回的结果

条件1（必须）：判断比较值和期待值的第一个逻辑条件

值1（必须）：当满足条件 1 时，返回的结果

条件2（可选）：判断比较值和期待值的第二个逻辑条件

值2（可选）：当满足条件 2 时，返回的结果

二、操作流程

在多维表格数据表中，点击数据表最右侧 + 新建字段，输入标题，将字段类型调整为 公式 即可。

在公式编辑器内，输入 IF() 函数，选择需要执行操作的字段，设置相应的逻辑条件即可。例如，判断公司各部门预算开支情况，可以采用 IF([预算额度]-[实际开支]<0,"超预算"，"未超预算") 函数公式。如下图显示，通过筛选得知“工程部”、“安全部”、“质检部”的实际开支均超过其预算额度，则返回值为“超预算”，否则返回值为“未超预算”。

在公式编辑器内，输入 IFS() 函数，选择需要执行操作的字段，设置相应的逻辑条件即可。例如，判断销售提成，可以采用 IFS([销售额]>=800,[销售额]*0.2,[销售额]>=500,[销售额]*0.1,[销售额]>=0,[销售额]*0) 函数公式。如下图显示，通过筛选计算销售额超过 800 元时，销售佣金为销售额的 20%；当销售额超过 500 元时，销售佣金为销售额的 10%；否则无佣金。

四、常见问题

问：编写公式时，为什么提示左侧缺少运算符？

答：在编写公式时，若被引用的数据表或数据字段左侧缺少运算符，将收到“左侧缺少运算符”的报错提示，此时需要在被引用的数据表或数据字段左侧添加运算符。例如公式：[任务管理].FILTER(CurrentValue[文本]).[任务名称]，紧邻 CurrentValue 的 [文本] 字段的左侧缺少运算符，需要增加相应的运算符。调整后公式：[任务管理].FILTER(CurrentValue.[文本]).[任务名称]。有关多维表格运算符的具体信息，请参考多维表格公式中常用的运算符号。

问：为什么使用多维表格 IFS() 函数时公式书写没有任何错误，结果却显示 #N/A？

答：当数据不满足 IFS() 中任意一个条件时其结果将为 #N/A，为避免这种情况，可以在公式最后添加一个特殊条件。例如：IFS([成绩]=100,"满分", [成绩] >=85,"优秀", [成绩] >=75,"良好", [成绩] >=60,"及格", TRUE,"不及格" ) ，上述公式中的 TRUE,"不及格" 即为一个特殊条件，即所有不满足前三个条件的数据结果都将显示为“不及格”。
