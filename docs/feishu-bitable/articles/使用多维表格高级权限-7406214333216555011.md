一、功能简介

部门成员仅可查看、编辑与自身业务相关的数据，保障数据安全。

为不同部门分配专属视图的查看权限，兼顾协作便利与数据隔离。

授权部门成员自主创建和维护业务仪表盘，减少对管理员的依赖。

仅对有需要的成员开放复制、下载、创建副本等权限，降低数据泄露风险。

为不同角色配置页面阅读权限，搭配页面自带的“跟随访问者权限统计”功能，实现同一页面对不同成员呈现不同数据。

多维表格的所有者和其他拥有可管理权限的协作者可开启并设置高级权限。

为非管理员角色授予仪表盘新增或编辑权限的功能正在内测中。

移动端仅支持查看高级权限及部分基础操作（如开启或关闭高级权限、为角色添加或移除成员）。

二、操作流程

开启高级权限

设置数据权限

设置数据表权限

可管理：对数据表拥有可管理权限，意味着可以新增、编辑、删除这个数据表内的所有记录、字段和视图。因此记录权限、字段权限和视图权限都默认取最大权限，不可修改。

可编辑：当数据表权限选择了 可编辑，你可以进一步设置记录、字段和视图的可编辑和可阅读的范围。

仅可阅读：当数据表权限选择了 仅可阅读，记录、字段和视图的详细权限只能设置为可阅读，你可以进一步设置可见范围。

无权限：无法访问此数据表。

设置记录权限

选中一个角色后，在 数据权限 标签页中选择一个数据表，在右侧的 详细权限 下，点击展开 记录权限。

选择该角色可对记录进行的操作，可选新增或删除记录。

设置可编辑的记录范围，如果在上一步选择了可删除记录，将同步设置可删除的记录范围。

所有记录：可编辑和删除数据表中的所有记录。

与成员本人相关的记录：仅可编辑和删除成员本人创建的记录，或特定字段中包含了成员本人的记录。

满足特定条件的记录：可编辑和删除满足特定条件的记录，需要继续设置记录需满足的条件。

如果第 3 步未选择所有记录均可编辑和删除，需要继续设置可阅读的记录范围。可选：

所有记录

与成员本人相关的记录

满足特定条件的记录

上述设置为可编辑的记录

设置字段权限

索引列不能被设置为不可见。

系统字段（即创建人、修改人、创建时间、最后更新时间字段）不能被设置为不可见。同时，由于系统字段的内容是自动填入的、不可编辑，因此不支持勾选 可新增 和 可编辑。

当数据表权限被设置为 可编辑 时，支持设置单选、多选选项的增删改权限。勾选字段的 自定义权限 后，向下滚动，可以看到 选项权限，下方有该数据表中的单选、多选字段，勾选即可完成配置。此处只能勾选当前角色有编辑权限的单选或多选字段。

注：已在该角色无编辑权限的记录中被使用的选项不支持被删除。

当数据表权限被设置为 可编辑 或 可阅读 时，支持设置附件字段的下载权限。勾选字段的 自定义权限 后，向下滚动，可以看到 操作权限，下方有该数据表中的附件字段。各角色默认可下载附件，你可以取消勾选，限制该角色下载机密内容。

在高级权限的 其他功能权限 中，若未勾选 创建副本、下载、打印多维表格，说明此角色不允许下载多维表格，此时默认不允许导出附件，附件导出的复选框无法勾选。

在通用的权限设置面板中（路径：多维表格右上角的 分享 > 权限设置），有 谁可以创建副本、打印和下载 的设置，用户需要同时满足通用权限和高级权限的权限要求，才能够进行操作。

注：在允许下载的基础上，用户只能下载自己可见（即有阅读权限）的附件字段的内容。

设置视图权限

对视图可见性的设置不包括个人视图，个人视图仍然是仅视图创建者自己可见。

若高级权限的设置中已对角色隐藏了部分视图，那么后续新建的视图默认对该角色不可见。如需调整，可手动修改。

设置仪表盘权限

系统角色中的 所有者 和 管理员（即对多维表格拥有可管理权限的用户）默认可以新建仪表盘，并拥有所有仪表盘的可管理权限，不支持更改。

250px|700px|reset

（内测中）选中需要授权的角色，在高级权限的 仪表盘权限 下进行配置：

勾选 允许新建仪表盘：该角色下的成员可以新建仪表盘，对自己新建的仪表盘进行编辑、删除、重命名等操作。成员新建仪表盘时，数据源仅可以选择自己有可管理权限的数据表。取消勾选后，该角色下的成员将无法新建仪表盘，同时失去对已新建仪表盘的操作权限。

选中单个仪表盘：为该角色下的成员授予该仪表盘的阅读、编辑权限，或将其设置为无权限。有编辑权限的成员可以编辑绑定了自己有可管理权限的数据源的仪表盘组件。

阅读者 角色无法被授予新建仪表盘权限，仅支持为其设置单个仪表盘的阅读权限。

非管理员角色在仪表盘中创建按钮组件时，无法为该组件配置“执行自动化”“执行工作流”“发送记录汇总”操作，也无法为图表类组件配置图表联动功能。

设置页面权限（内测中）

系统角色中的 所有者 和 管理员（即对多维表格拥有可管理权限的用户）默认可以新建页面，并拥有所有页面的可管理权限，不支持更改。

其他角色仅支持设置为 仅可阅读 或 无权限。选中需要授权的角色，在高级权限的 页面权限 下选择目标页面，配置对应权限：

仅可阅读：角色成员可在多维表格内打开该页面。

无权限：不向角色成员展示该页面入口。

设置文件夹可见性

如果文件夹中包含文档，则即使该角色对文件夹中所有数据表和文档均无访问权限，也可以看到该文件夹。

如果文件夹中仅包含工作流，文件夹将对该角色隐藏。

四、常见问题

问：为什么我无法看到“升级新版高级权限”的入口？

答：2023 年 4 月以前创建的多维表格暂时无法升级，后续将支持升级。

4. **边界与上限**：若文档提到数量上限、格式限制、导入导出约束，需在实现与错误提示中体现。
