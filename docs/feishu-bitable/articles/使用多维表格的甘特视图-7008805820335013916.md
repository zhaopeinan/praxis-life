一、功能简介

未开启高级权限时，需要对多维表格有可编辑或可管理权限。

开启高级权限时，需要在 数据表权限 内拥有 可管理 的权限；或是在 数据表权限 内拥有 可编辑 的权限，且在 视图权限 内拥有 可新增、删除、修改视图 的权限。

二、操作流程

创建甘特视图

创建甘特视图后，你可以重命名视图，复制、删除、移动视图，也可以在视图中使用分组、筛选、排序等功能，具体信息请参考使用多维表格视图。如需在甘特视图中显示或隐藏字段、冻结字段等，具体信息请参考使用多维表格字段。

配置甘特图

打开多维表格，进入甘特视图，可以设置甘特图中长条的起止时间、标题、颜色等。

设置长条的起止时间：点击 甘特图配置，在 开始日期 和 结束日期 处选择类型为“日期”或“创建时间”的字段，也可以选择格式为日期的公式字段。

选择“日期”类型的字段时，可以通过拖拽长条的方式快速更改起止日期。

拖拽整个时间条，可同时更改起止时间。

拖拽时间条的左端或右端，可对应地更改开始时间或结束时间。

设置长条的标题：点击 甘特图配置，在 标题展示 处选择字段，各个长条上将展示所选字段中的对应内容。

设置长条颜色：点击 甘特图配置，在 颜色显示 处按需选择以下选项：

自定义颜色：为所有长条选择统一的颜色。

跟随字段颜色：选择原始数据表中的某个单选字段，为各个长条应用该单选字段中对应选项的颜色。

按条件填色：设置填色条件，为符合条件的长条填充指定颜色。

仅计算工作日：开启 仅计算工作日 并自定义工作日规则，长条中的非工作日会置灰展示，长条右端所统计的任务总时长将剔除非工作日时间。

点击 甘特图配置，开启 仅计算工作日 的开关。下方会出现 工作日规则 的字样，点击 设置 进入自定义配置。

按需勾选每周的固定工作日，点击 添加其他工作日 可以按需添加其他自定义工作日。如果勾选 法定工作日（含节假日调休），则根据国务院办公厅每年的节假日安排，自动识别工作日和非工作日。配置完成后点击 确定。

设置里程碑

将鼠标悬停在甘特视图横轴的任意日期上，点击该日期，输入里程碑名称，按下回车键或点击其他空白区域，即可添加里程碑。

点击已创建的里程碑的名称，可以修改名称，点击 删除 图标可以删除该里程碑。

调整甘特图的展示

宽屏查看甘特图

点击页面左上方导航栏旁的 << 图标，可折叠数据表信息；点击甘特视图展示字段左上角的 << 图标，可折叠甘特视图中左侧的字段。

隐藏后，点击页面左上方的 >> 图标即可重新展示数据表等信息。点击视图左上角的 >> 图标即可重新展示甘特视图中左侧的字段。

快速定位起止日期：当时间条未显示在可见范围时，点击时间条两侧的 ← 或 → 按钮，可快速跳到该时间条的开始或结束日期。此外，你也可以点击右上角的 今天 快速定位到今天的时间位置。

调整时间条的展示维度：点击右上角的 周、月、季、年 的选项，可调整时间条的展示维度。甘特视图默认的选择是 月。如果任务的时间跨度较大，你可以选择 季 或 年，提升信息展示的效率，查看更便捷。

三、常见问题

问：多维表格的甘特视图是否支持设置任务之间的依赖关系或前置后置任务？

答：不支持。

问：多维表格的甘特视图是否可以设置在时间条上显示任务进度？

答：可以。要在甘特视图的时间条上显示进度，可以在数据表中创建一个进度字段，并在 甘特图配置 中将 标题展示 设置为该进度字段。

问：在多维表格的甘特视图中，如何添加子任务或查看任务的关联关系？

答：不支持在甘特视图中添加子任务。但你可以在表格视图中添加子记录或关联字段后，在甘特视图的 字段配置 中显示父记录或者对应的关联字段，即可在甘特视图中查看任务的关联关系。你也可以在甘特视图中按照父记录或关联字段进行分组，以便更清晰地展示任务的所属关系。250px|700px|reset250px|700px|reset
