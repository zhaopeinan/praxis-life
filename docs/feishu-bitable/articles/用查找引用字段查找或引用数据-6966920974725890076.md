二、操作流程

打开多维表格数据表，在表格视图中，点击字段名最右侧的 + 图标。输入字段标题，并在字段类型列表中选择 查找引用。

选择被引用的数据：

引用字段所在的数据表：被引用数据所在的数据表。

选择引用字段：被引用数据的字段名。

注：多维表格所有类型的字段都可被引用，引用字段保留源字段的格式。

设置查找条件，即被引用数据需要满足的条件。

引用表中的字段：被引用数据所在数据表中的一个字段。

条件：根据所选择字段类型的不同，你可以选择等于、不等于、包含、为空、不为空等条件。

当前数据表中的字段或自定义值：当前数据表中的一个字段或一个自定义值。

注：当添加多个条件时，你可以选择符合 所有 还是 任一 条件。

设置引用字段的计算方式和格式：

计算方式：设置被引用字段中数据的计算方式。

原值：显示符合查找条件的全部源数据，并以源数据的样式展现。

去重：去除查找到的数值中的重复值，并以源数据的样式展现。

去重计数：去除查找到的数值中的重复值，对去重结果计数。

求和：显示查找到的数值的总和。

计数：显示总共查找到几个数值。

平均值：显示查找到的数值的平均值。

最大值：显示查找到的数值的最大值。

最小值：显示查找到的数值的最小值。

字段格式：设置引用字段的格式。

如果 计算方式 选项选择了 原值 或 去重，字段格式 将自动设置为与被引用字段相同的格式，且无法修改。

如果 计算方式 选择除 原值 和 去重 外的其他选项，此处可选 数字，日期，或 货币。

当选择了某些字段格式后，配置面板底部会提供针对该格式的配置选项。例如，当 字段格式 为 数字 时，可继续使用 数字格式 选择数字保留几位小数。

当被引用字段的格式发生改变时，引用关系将失效。此时需重新设置引用字段以恢复引用。

如果使用日期字段作为查找条件，在查找时将使用创建日期字段时设置的初始 日期格式 作为查找条件。例如，如果查找条件中的两个日期字段的初始格式分别为 2025/01/30 和 2025/01/30 17:00，即使在查找前将 2025/01/30 17:00 转换为 2025/01/30，查找时二者也不会被视为相等。

三、场景实践

任务管理

数据表：

任务分配表，记录了具体任务、跟进人、时间周期、完成进度等信息。

任务跟进状态表，用来统计每位成员负责的任务个数和具体任务。

场景：在任务跟进状态中，负责人希望了解每位成员所负责的任务个数和具体任务是什么。

步骤：在 任务跟进状态 中新建一个查找引用字段，选择信息源数据表 任务分配，选择要引用的信息 任务描述。设置查找条件，让源数据表中的 负责人包含 现数据表中的 成员姓名，引用结果的呈现方式选择 原值。

素材管理

库存管理表，记录了货品的名称、类型、图片资料、出入库时间等信息。

品类管理表，按照货品类型统计各类货品的信息。

场景：在品类管理中，负责人希望通过图片直观了解每个货品类型下都有哪些商品。

步骤：在 品类管理 中新建一个查找引用字段，选择信息源数据表 库存管理，选择要引用的信息 图片资料。设置查找条件，让源数据表中的 货品类型等于 现数据表中的 货品类型，引用结果的呈现方式选择 原值。

数据管理

“项目一”数据汇总表，记录了“项目一”在各推广渠道每一天的浏览次数。

渠道数据表：按照推广渠道对投放数据进行统计。

场景：在项目数据整理中，负责人希望统计出在五一期间段内各渠道浏览次数的总和。

步骤：在 渠道数据 中新建一个查找引用字段，选择信息源数据表 项目一数据汇总，选择要引用的信息 浏览次数。在查找条件中，设置 3 个条件：发布渠道 等于 推广渠道，发布日期 晚于 五一开始，发布日期 早于 五一结束。

四、常见问题

问：使用多维表格查找引用字段时，为什么查找引用部分或所有结果没有显示？

答：可能有以下三种原因：文本前后含有空格：如果查找条件中所选的字段类型为文本且部分结果未显示时，可以返回原表格，点开空结果所对应的单元格，查看文本前后是否含有 空格， 此时删除空格既能正常显示结果；日期字段含有时分秒：如果查找条件中所选的字段类型为日期且所有结果都为空时，请检查原字段中的日期是否含有时分秒，此时请在原数据表中新建一个公式字段对日期进行取整后重新设置查找引用字段即可如果设置的查找条件是基于某个公式字段的值，当公式字段的计算结果错误时，将不会被统计到查找引用的字段中。250px|700px|reset250px|700px|reset

问：一个多维表格查找引用字段可以同时引用多个字段吗？

答：不可以。每个查找引用字段只能引用一个字段。可以通过创建多个查找引用字段来引用不同数据表中的不同字段。

问：使用多维表格查找引用字段时，我能设置哪些查找条件？

答：当前在查找条件中支持设置等于和不等于、包含、为空和不为空、早于和晚于（仅日期字段）。

问：使用多维表格查找引用字段时，我最多能添加多少个查找条件？

答：当前最多支持添加 5 个查找条件。

问：可以在文档和表格的多维表格使用查找引用字段吗？

答：可以。你可以在文档或表格中添加多个数据表，并在多个数据表之间查找引用数据。

问：哪些字段可以被多维表格查找引用字段引用和查找？

答：多维表格的所有字段类型都可被查找引用字段所引用，引用字段保留源字段的格式。如果被引用字段为单向或双向关联字段，将默认对关联的记录进行去重。多维表格的所有字段类型都能被用来作为查找条件。

问：多维表格查找引用字段可以查找被隐藏的字段吗？

答：可以，被隐藏的字段也将出现在查找引用字段面板的下拉列表中，点选即可将该字段设为源数据或查找条件。

问：多维表格查找引用字段的查找结果会实时更新吗？

答：查找结果会实时更新。若源数据被修改，查找结果也将显示为更新后的数据，无需多次更新。

问：查找引用字段可以跨多维表格文件查找数据吗？

答：暂时不能。当前仅支持在同一多维表格、文档或表格文件中使用查找引用字段。

问：为什么我不能修改多维表格查找引用字段的内容？

答：查找引用字段的内容是通过引用自动生成的，需要在被引用的数据表中才能修改该字段的内容。
