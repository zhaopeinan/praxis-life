# 科研管理模板（论文 / 投稿线）设计

**状态：** 已实现  
**范围：** 新增 DuoWei 一键模板 `research`（界面名：科研管理），不改动通用产品能力。

## 目标

为个人 / 小团队提供「论文主线 + 过程任务 + 投稿历史」的起步结构：

- 主线状态可看板、截稿可进日历与飞书
- 读文献 / 实验 / 写作等过程以**任务行**挂在论文下，不塞进论文状态机
- 换投稿以**投稿记录**多行表达，不靠改一个 venue 字段抹掉历史

## 非目标（首版不做）

- 独立文献库、实验样本库、合作者通讯录
- 审稿意见结构化多表
- 双向关联对称字段（首版单向 `link` 即可）
- 跨表字段插值增强（任务飞书文案仅用本表字段）

## 数据模型

### 表：论文

| 字段 | 类型 | 选项 / 说明 |
|------|------|-------------|
| 标题 | text | 暂定名 / 题目 |
| 摘要要点 | long_text | 可选 |
| 状态 | single_select | 选题、写作中、投稿中、返修中、已录用、已拒稿、已搁置 |
| 优先级 | single_select | P0、P1、P2、P3 |
| 目标会议/期刊 | text | 当前瞄准 venue |
| 截稿日期 | date | 日历与飞书摘要 |
| 负责人 | text | |
| 备注 | long_text | |

### 表：任务

| 字段 | 类型 | 选项 / 说明 |
|------|------|-------------|
| 标题 | text | |
| 所属论文 | link → 论文 | |
| 类型 | single_select | 读文献、实验、写作、改图、投稿事务、其他 |
| 状态 | single_select | 待办、进行中、已完成、已搁置 |
| 截止日期 | date | |
| 说明 | long_text | 可选 |

### 表：投稿记录

| 字段 | 类型 | 选项 / 说明 |
|------|------|-------------|
| 所属论文 | link → 论文 | |
| 会议/期刊 | text | 本次投递 venue |
| 投稿日期 | date | |
| 结果 | single_select | 审稿中、接收、小修、大修、拒稿、撤稿 |
| 通知日期 | date | |
| 意见摘要 | long_text | |

创建顺序：先建「论文」，再建成「任务」「投稿记录」（以便 `linkTableId` 指向论文）。

## 视图

**论文：** 表格（默认）、看板（状态）、日历（截稿日期）、进行中（排除 已录用 / 已拒稿 / 已搁置）

**任务：** 表格（默认）、看板（状态）、日历（截止日期）、未完成（排除 已完成 / 已搁置）

**投稿记录：** 表格（默认）、审稿中（结果 = 审稿中）

## 示例数据

- 论文 1：示例：多模态检索 · 写作中 · P0 · 目标 CVPR · 截稿约 +14 天  
- 论文 2：示例：小样本分割 · 投稿中 · P1 · 目标 ICCV  
- 任务 ×3（关联论文 1）：精读 survey、补消融实验、整理 contribution  
- 投稿记录 ×2（关联论文 2）：ICCV 审稿中；可选一条历史 workshop 拒稿

## 自动化与集成

- 沿用 Base「日历 / 飞书」Webhook 配置
- 自动化（默认启用）：
  1. 论文 `record_created` → `feishu_bot`（标题、状态、目标会议/期刊、截稿日期）
  2. 任务 `record_created` → `feishu_bot`（标题、类型、截止日期）
  3. 论文 `schedule daily:09:00` → `feishu_digest`（截稿日期，排除 已录用 / 已拒稿 / 已搁置，`daysAhead: 7`）
  4. 任务 `schedule daily:09:00` → `feishu_digest`（截止日期，排除 已完成 / 已搁置，`daysAhead: 7`）
- 日历：用户在「日历 / 飞书」对论文表、任务表生成 ICS；模板描述中说明

## 产品入口

- `TEMPLATES` 增加：`id: "research"`，`name: "科研管理"`，描述点明论文 / 任务 / 投稿记录与飞书、日历
- `createTemplate` / MCP `create_base_from_template` 枚举加入 `research`
- 「个人待办」描述可改为不再强调「科研」为唯一场景（可选小改，非必须）
- 测试：创建模板后断言三表名、关键视图类型、自动化动作类型存在；关联字段指向论文表

## 验收

1. 界面「从模板新建」可选「科研管理」，一键得到上述三表与视图  
2. 示例任务的「所属论文」指向示例论文  
3. 配置飞书 Webhook 后，新建论文/任务可推送；日摘要可手动/定时触发  
4. 论文、任务可导出或订阅 ICS
