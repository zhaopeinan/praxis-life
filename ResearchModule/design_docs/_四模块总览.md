### 相对原六族的关键纠偏

1. `假设登记` 与 `09 红队审查` **定义权迁入模块 01**（原属族三 / 第 09 讲）。
2. `02 差异假设`（`G-` 候选池）与 `假设登记`（`H-` 正式出口）两表分立，不合并。
3. 模块 03 建实验相关表时，`假设` 关联**只允许**指向模块 01 出口视图中的记录；禁止从 `02 差异假设` 直接挂实验。
4. 原族六（23–24）不单独成第五模块，沉入横切共享层；各模块可引用，不阻塞 01→04 主线。

## 2. 主线实体与跨模块接口

```text
M01: 问题矩阵 → 差异假设/空白三问 → 可行性冲刺 → 假设登记(+红队)
         │                │
         │                └─→ M02 定向检索 / 文献回填
         └─→ M04 主张来源

M02: 检索式/日志 → 文献库 → 综述/关系/主题索引
         │
         └─→ M04 Related Work 原料

M03: 实验矩阵/预期卡 → 消融 → 配置台账 → 实验记录(+代码/数据/调试)
         │
         └─→ M04 实验证据

M04: 稿件/段落卡 → 图表 → 投稿 → 合规/回应 → 核查清单
```

### 接口键（硬约束）

| 从 → 到 | 键 / 表 | 规则 |
| --- | --- | --- |
| M01 → M03 | `假设登记.编号`（`H-`） | 仅出口视图内记录可被实验表关联 |
| M01 → M02 | `02 差异假设` / `假设登记` → `05 检索日志` | 定向检索需求从假设指出 |
| M01 → M02 | 代表工作 / 最接近工作 → `文献库` | P0 可先多行文本；核实后回填关联 |
| M02 → M04 | `文献库` / `07 对照条目` → `17 段落卡` | Related Work 原料 |
| M03 → M04 | `实验记录` / `18 图表台账` → `稿件` | 证据挂靠 |
| 任意 → 横切 | `提示词库`、`复核记录`、`模板库` | 共享；字段在定义模块一次性定死 |

### 模块 01 → 模块 03 出口门禁（不可放宽）

下游只认同时满足以下条件的 `假设登记` 记录：

1. `可证伪条件` 非空
2. `要素齐备` = 六项齐全
3. 关联的 `09 红队审查` 三轮均已有结论且需修订项已处置（非「无行动」搁置）
4. `审定状态` = 已审定
5. `状态` ∈ {已收紧待验证, 验证中, 得到支持}（已证伪 / 搁置 / 待审查不可挂新实验）

闸门视图建议名：`可进入实验`（定义于 `_模块01_选题与假设.md`）。

## 4. 实施顺序与门禁

### 标准工法（每个模块）

1. **收资料**：方法要点 / 改动意图 / 样例；对照现有讲次标「保留 / 合并 / 废弃 / 新增」
2. **写契约**：只改该模块契约文件 + 必要全局索引
3. **落空间**：MCP / `ResearchModule/build` 建表、视图、自动化、智能体种子；`--verify` 验收
4. **门禁**：出口视图可用、跨模块接口字段就位 → 才开下一模块资料窗口
5. **禁止**：未收齐资料时实现后续模块私有表；不拆多 base
