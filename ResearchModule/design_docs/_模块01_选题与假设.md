## 1. 模块目标与出口

**主问题**：做什么；主张是否可证伪。

**主线**：

```text
01 问题矩阵
  → 02 差异假设（G-）+ 02 空白三问
    → 03 可行性冲刺（继续 / 放弃备忘录）
      → 假设登记（H-）+ 09 红队审查
        →【出口】可进入实验
```

**旁路留痕**：`04 选题决策日志`、共享 `复核记录`、共享 `提示词库`。

**模块出口（给模块 03 的硬接口）**：视图 `可进入实验` 中的 `假设登记` 记录。过滤条件见 §5；禁止从 `02 差异假设` 直接挂实验。

## 3. 字段契约（摘要；以落地要点为准）

字段写法、选项值、自动化与智能体的完整清单见 `_各讲落地要点.md` 对应节。此处只钉**模块级必须成立的约束**。

### 3.1 主链约束

| 环节 | 必须成立 |
| --- | --- |
| 问题矩阵 | AI 生成默认 `核实状态=待核实`；`个人匹配度` 只允许人填；核实通过才进优先候选 |
| 差异假设 | 须有 `立案来源`（指向矩阵）或显式评论说明无来源；差异维度至少两类；三问是仪表盘不是一次性关卡 |
| 可行性 | 仅 `状态=存活` 的 `G-` 可进冲刺；结论 ∈ {继续投入 / 暂停观察 / 果断放弃}；放弃必有备忘录 |
| 假设登记 | 六要素 + `可证伪条件` 非空才算出生；已证伪保留不删；**定义权在本模块** |
| 红队 | 人写草稿 → AI 攻击 → 人修订；三轮齐且处置完成，才允许进入出口视图 |

### 3.2 `假设登记` 关键字段（定义于本模块）

- `编号`（自动编号 `H-`）
- `假设陈述`（多行，六要素一句话）
- 六要素拆解：`条件` / `方法` / `基线` / `指标` / `幅度` / `机制`
- `要素齐备`（单选或公式：六项齐全 / 缺项待补）
- `来源`（关联→`02 差异假设` / `03 可行性冲刺`，多值）
- `可证伪条件`（多行）
- `优先级`、`排序依据`、`状态`、`风险备注`、`基线强度自查`
- `关联配置`（→`配置台账`，模块 03 建表后接通）、`关联段落`（→`17 段落卡`，模块 04 接通）
- `证伪记录`、`审定三件套`

跨模块关联字段在目标表尚未建成时：**字段延后**，与现有 `build-base.mts` 策略一致；出口门禁不依赖这些延后字段。

### 3.3 审定与 AI 红线

- 凡 AI 可写字段所在表必须有审定三件套。
- AI **不得**直接改：`个人匹配度`、`核实状态`、`假设登记.状态`（人审定后改）、核查类结论。
- 红队智能体只写 `09 红队审查` 草稿（待审定）。

### 4.2 模块出口视图（新增）

**`可进入实验`**（grid，绑定 `假设登记`）

过滤（AND）：

1. `可证伪条件` 非空
2. `要素齐备` = 六项齐全
3. `审定状态` = 已审定
4. `状态` ∈ {已收紧待验证, 验证中, 得到支持}
5. 红队三轮齐且无「需修订 + 处置=无行动」积压——若平台无法在单视图表达关联计数，则用配对闸门：本视图 + `假设登记` 侧「红队未齐」清单长期为空作为操作纪律；自动化 `三轮未齐提醒` 保留

排序：`优先级` 降序。

模块 03 的实验表建关联时，文档与培训口径统一为：**只从本视图挑 `H-`**。

## 5. 自动化与智能体（批次范围）

落空间时按落地要点装配；本模块批次包含：

- 矩阵：新增即待核实 / 待核实积压提醒 / 核验通过证据链提示
- 差异：三问通过给节奏 / 重检巡检 / 立案来源回填
- 冲刺：超时提醒 / 放弃即归档 / 红色缺口登记
- 决策与复核：预期验证点到期 / AI 产出挂复核（矩阵） / 决策未写预期
- 假设与红队：证伪即入档 / 缺证伪条件不放行 / 六要素缺项提醒 / 三轮未齐提醒

智能体：`问题地图纠偏员`、`隐藏格探测员`、`魔鬼代言人`、`二问专审员`、`MVE 审问者`、`去热点化审查员`、`红队审查员`。

提示词一律进 `提示词库`，带版本号。

仪表盘：`选题雷达`（原第 01 讲）保留，作为模块 01 总览。

## 7. 分期与验收

### P0（资料定稿后一次落地）

1. 建齐 §2 表（含 `提示词库`、`复核记录`、`假设登记`）
2. 建齐 §4 视图（含出口 `可进入实验`）
3. 装配 §5 自动化与智能体种子；提示词入库
4. 建仪表盘 `选题雷达`
5. `--verify`：字段名/类型、视图过滤、自动化名与触发器与契约一致

### 验收标准

1. 从优先候选单元格能立案到 `G-`，三问与冲刺路径可走通
2. 「继续投入」可晋升为 `H-`（规则以用户资料为准，见 §8）
3. 缺证伪条件 / 六要素缺项 / 红队未齐的记录**不出现在** `可进入实验`
4. 已证伪假设仍在 `已证伪档案`，编号不复用删除
5. AI 生成矩阵格自动待核实，且可挂到 `复核记录`

## 9. 与原文 / 原六族的偏差

| 偏差 | 原设计 | 本模块 | 理由 |
| --- | --- | --- | --- |
| 假设定义讲次 | 第 09 讲（族三） | 模块 01 | 用户锁定「选题与假设」吃到可证伪假设 |
| 族一出口 | 存活 `G-` + 决策日志 | `H-` 出口视图 | 实验侧不得消费未证伪设计的候选 |
